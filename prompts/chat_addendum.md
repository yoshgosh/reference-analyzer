# チャットでの追加ルール（上位規則）

本節は前掲の指示文に対する差分であり，**矛盾する場合は本節を優先する**．
抽出した内容を，Notion のコネクタ（`notion-*` のツール）で自ら登録する．

## 1. 進め方

- ユーザーへの確認は求めず，登録まで一度に進める．新しいタグの追加も確認しなくてよい．
- 判断できない項目は推測で埋めず，空欄にする．空欄にした項目は最後に報告する．
- 同名・同じ論文のページが既にあっても，新しいページを作る（重複は確認しない）．

## 2. 登録先

```
data_source_id: {{NOTION_DATA_SOURCE_ID}}
```

| プロパティ名   | 内容                     | 形式           |
| -------------- | ------------------------ | -------------- |
| `Citation Key` | 引用キー                 | タイトル       |
| `Title`        | 原文タイトル             | テキスト       |
| `DOI`          | DOIリンク／公開URL       | URL            |
| `Summary`      | 概要（一段落）           | テキスト       |
| `Tag`          | 選択タグ                 | マルチセレクト |
| `Author`       | 著者（所属）・公開者     | テキスト       |
| `Year`         | 出版年・公開年           | 数値           |
| `Publication`  | ジャーナル／会議／公開元 | テキスト       |
| `Citation`     | BibTeX                   | テキスト       |
| `Rating`       | 重要度評価               | セレクト       |
| `Favorite`     | お気に入り               | セレクト       |

- プロパティ名は**正確に**この表のとおりに書く．
- `Favorite` は設定しない（空のままにする）．
- `Rating` と `Favorite` の選択肢は固定である．追加・変更してはならない．
  選択肢の文字列は推測せず，`notion-fetch` で取得した値をそのまま使う
  （見た目が同じでも異体字セレクタの有無で別の文字列になり，400 で拒否される）．

## 3. 登録の手順

1. `notion-fetch` で `collection://{{NOTION_DATA_SOURCE_ID}}` を取得し，`Tag` の現在の選択肢と
   色をすべて書き出す．前掲の既存タグの一覧は作成時点のものなので，こちらを正とする．
2. 新しいタグがあれば，ページを作る**前に**選択肢へ追加する．未登録の値のままページを作ると
   400（validation_error）で拒否される．

   ```
   notion-update-data-source
   data_source_id: {{NOTION_DATA_SOURCE_ID}}
   statements: ALTER COLUMN "Tag" SET MULTI_SELECT('既存1':blue, '既存2':green, …, '新規':色)
   ```

   **`SET MULTI_SELECT(...)` は全置換である．** 手順1で得た既存の選択肢を**すべて**，元の色の
   まま列挙した上に新しいものを足す．既存の選択肢を省くと，それらがデータベースから削除される．
3. 代表画像を用意する（§4）．
4. `notion-create-pages` で，親を `data_source_id: {{NOTION_DATA_SOURCE_ID}}` としてページを作る．
   本文は「代表画像（キャプション付き）→「要約の作成」で作った要約」の順に置く．
5. 作ったページを `notion-fetch` で取得し直し，プロパティ・代表画像・本文が入っていることを
   確かめる．

## 4. 代表画像

次の順で試す．取得した画像が**対象と同一の資料のものである**ことを確かめる
（「Web検索で得た情報の扱い」）．**ページ全体を代表画像にはしない**（本文が写り込む）．

1. **公開されている元画像の URL を使う．** arXiv の HTML 版（`https://arxiv.org/html/<ID>`）や
   出版社のページにある図の URL を，`notion-create-attachment` の `source_url` に渡す．
2. **PDF から取り出す．** コード実行が使えるなら，PDF から図を画像として取り出す
   （埋め込み画像の抽出，またはページを画像化して図の範囲を切り出す）．
   `notion-create-file-upload` で受け付け先を作り，コード実行から画像を送る．
   1・2 とも，応答の `suggested_markdown`（または `markdown_source`）で画像を本文の先頭に置き，
   キャプションを付ける．
3. **どちらもできない場合は，画像なしでページを作り，ユーザーに委ねる．** 取り出した画像を
   ファイルとして渡せるなら渡し，渡せなければ図表番号と頁を示して，ページの先頭に貼るよう伝える．
   この場合，登録は**未完了**として報告する．

## 5. 最後の報告

登録が終わったら，次を短く報告する．

- 作成したページの URL
- Citation Key と，PDF を改名する場合の名前（`<Citation Key>.pdf`）
- 追加した新しいタグ（あれば）
- 代表画像をどの方法で入れたか．入れられなかった場合はその理由と，ユーザーが行うこと
- 空欄にした項目と理由（あれば）
- 使わなかった補助資料と理由（あれば）
